# SofunAI Studio

FreeAll is published and maintained by SofunAI Studio. The studio logo is independent of the FreeAll product name and icon.

FreeAll 由 SofunAI 工作室出品并维护。工作室 logo 独立于 FreeAll 产品名称与图标。

Use `sofunai-logo-light.svg` on light backgrounds and `sofunai-logo-dark.svg` on dark backgrounds. `sofunai-mark.svg` is the square symbol; `tokens.json` holds the shared palette. These are self-contained SVGs with transparent backgrounds.

浅色背景使用 light 字标，深色背景使用 dark 字标；mark 为方形标识，tokens.json 为工作室配色。SVG 均为透明背景、自包含素材。

The README and application About page identify the studio. Preserve the original [brand asset license](LICENSE) when reusing these files.

README 与应用关于页均标注工作室，复用时保留原[素材许可](LICENSE)。
